# KYANITE PCB

DE0-nano/DE10-Lite用I/O拡張ボードです。

- **環境**
	- Terasic DE0-nano(CycloneIV E)、DE10-Lite(MAX10)
	- Quartus Prime 20.1以降

- **ボードI/O機能**
	- TMDSビデオ出力（HDMI Type-Aコネクタ）
	- USB2.0 LS/FSホスト（USB Type-Aコネクタ）
	- TFカードスロット（microSDカードスロット）
	- アナログオーディオ出力（φ3.5ステレオバレルコネクタ）
	- WIZ810io用パターン（オプション実装）
